# 爪记一生 · 标志说明

> 这个标记是我（和 DeepSeek Harness）一起画的矢量图，坐标是手写的 SVG，没有使用任何图标库、字体或他人素材。你可以自由改动、继续衍生成一套视觉。

## 1. 它在说什么

三个元素，一句话：

- **一条不闭合的弧** —— 一天一天绕过来，就是一年；
- **弧的起点一个圆点** —— 第一天，从这一笔记起；
- **弧里踩下的爪印** —— 它。

合起来：**从第一笔开始，绕成它的一生。**

## 2. 颜色

| 用途 | 值 |
|---|---|
| 墨（深底 / 主文字） | `#2B2520` |
| 米（浅底 / 深底上的图形） | `#F7F0E4` |
| 暖红（唯一强调色，只用在那个点上） | `#C2613F` |

一条规矩：**暖红只出现一次**。它是「起点」，用多了故事就散了。

## 3. 几何（要改就按这个比例改）

| 元素 | 参数 |
|---|---|
| 画布 | 240×240 |
| 弧 | 圆心 (120,120)，半径 76，线宽 12，圆头端点，开口约 45°（左上方） |
| 起点圆点 | 圆心 (66.3, 66.2)，半径 12 —— 正好压在弧的端点外侧 |
| 爪趾 | 四个椭圆，rx 9.5–10.5 / ry 13–14，角度 −18°~18° 扇形排开 |
| 爪垫 | 宽约 52、高约 46 的圆角块，中心 (121.5, 133) |

## 4. 怎么用

| 场景 | 用法 |
|---|---|
| 小程序头像 | 深底 + 米色图形 + 暖红点（`app-icon-512.png`） |
| 启动页 / 分享图 / 白底界面 | 浅底 + 墨色图形（`icon-light-512.png`） |
| 极小尺寸（≤48px） | 只留弧 + 爪印 + 点，线宽可加到 15（见 `screenshots/icon-512.png` 的 64px 版） |
| 单色印刷 | 全用墨或全用白，那个点保持同色（不失故事） |

**留白**：图形外缘到画布边至少留 12% 的空。

**别这么做**：不要给弧加渐变、不要给爪印描边、不要把点挪到别处、不要把爪印换成别的动物（猫狗都用同一枚）——它是「一类」而不是「某一只」。
